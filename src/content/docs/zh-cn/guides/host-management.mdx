主机管理是 EasyShell 的基础。在执行脚本或使用 Web 终端之前，您需要将服务器注册为受管主机。

## 添加主机

在 Web 界面中导航到 **主机管理** → **添加主机**。您可以通过两种方式添加主机：

### 手动注册

手动输入主机信息：
- **主机名 / IP** — 服务器的可达地址
- **SSH 端口** — 默认为 22
- **认证方式** — 密码或 SSH 密钥
- **标签** — 用于组织主机的键值对（例如 `env:production`、`role:web`）

### 通过 Agent 自动发现

如果 Agent 已经部署在目标主机上，它会自动向服务器注册。Agent 发送的注册请求包含：
- 主机名和 IP 地址
- 操作系统和内核版本
- CPU 架构
- 可用资源（CPU 核心数、内存、磁盘）

## 主机详情

每个主机的详情页面显示：

- **系统信息** — 操作系统、内核、架构、运行时间
- **资源指标** — CPU 使用率、内存利用率、磁盘 I/O、网络吞吐量（每 60 秒更新一次）
- **Agent 状态** — 连接状态、最后心跳时间、Agent 版本
- **执行历史** — 近期脚本执行记录及状态和持续时间

## 使用集群组织主机

集群允许您将相关主机分组以进行批量操作。常见的集群策略：

| 策略 | 示例 |
|------|------|
| 按环境 | `production`、`staging`、`development` |
| 按角色 | `web-servers`、`db-servers`、`workers` |
| 按地域 | `us-east`、`eu-west`、`ap-southeast` |

创建集群：
1. 进入 **主机管理** → **集群**
2. 点击 **创建集群**
3. 输入名称和可选描述
4. 通过选择或标签筛选将主机添加到集群

## 批量操作

选择多个主机或整个集群来执行批量操作：
- **执行脚本** — 在所有选定主机上运行脚本
- **更新 Agent** — 向选定主机推送 Agent 更新
- **标签管理** — 批量添加或删除标签
- **导出** — 将主机信息导出为 CSV

## 主机健康监控

EasyShell 使用颜色编码的状态系统显示主机健康状况：

| 状态 | 指示器 | 含义 |
|------|--------|------|
| 健康 | 绿色 | Agent 已连接，所有指标正常 |
| 警告 | 黄色 | Agent 已连接，资源超过阈值 |
| 危险 | 红色 | Agent 已连接，资源严重耗尽 |
| 离线 | 灰色 | 超过 3 个间隔未收到心跳 |
