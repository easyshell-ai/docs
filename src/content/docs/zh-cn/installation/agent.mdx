EasyShell Agent 是一个轻量级 Go 二进制文件，运行在每台受管主机上。它负责脚本执行、指标收集和实时日志流传输。

## 特性

- **单一二进制文件** —— 无运行时依赖，部署简单
- **跨平台** —— Linux（amd64、arm64）、macOS
- **低开销** —— 通常内存占用低于 20 MB
- **自动注册** —— Agent 首次启动时自动向 Server 注册
- **自愈能力** —— 网络中断时自动重连

## 安装

### 预编译二进制文件

下载适合你平台的最新 Agent 二进制文件：

<Tabs>
  <TabItem label="Linux amd64">
    ```bash
    curl -fsSL https://github.com/easyshell-ai/easyshell/releases/latest/download/easyshell-agent-linux-amd64 -o /usr/local/bin/easyshell-agent
    chmod +x /usr/local/bin/easyshell-agent
    ```
  </TabItem>
  <TabItem label="Linux arm64">
    ```bash
    curl -fsSL https://github.com/easyshell-ai/easyshell/releases/latest/download/easyshell-agent-linux-arm64 -o /usr/local/bin/easyshell-agent
    chmod +x /usr/local/bin/easyshell-agent
    ```
  </TabItem>
</Tabs>

### 从源码构建

```bash
cd easyshell-agent
GOOS=linux GOARCH=amd64 go build -o easyshell-agent-linux-amd64 ./cmd/agent
```

## 配置

Agent 通过环境变量或配置文件进行配置：

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `EASYSHELL_SERVER_URL` | `http://localhost:18080` | Server API 地址 |
| `EASYSHELL_AGENT_NAME` | 主机名 | Agent 显示名称 |
| `EASYSHELL_HEARTBEAT_INTERVAL` | `30s` | 心跳频率 |
| `EASYSHELL_METRICS_INTERVAL` | `60s` | 指标上报频率 |

## 作为服务运行

为 Agent 创建 systemd 服务：

```ini
[Unit]
Description=EasyShell Agent
After=network-online.target
Wants=network-online.target

[Service]
Type=simple
ExecStart=/usr/local/bin/easyshell-agent
Restart=always
RestartSec=5
Environment=EASYSHELL_SERVER_URL=https://easyshell.example.com

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload
sudo systemctl enable easyshell-agent
sudo systemctl start easyshell-agent
```

## 通信协议

Agent 使用两种协议与 Server 通信：

- **HTTP** —— 注册、心跳（30 秒间隔）、指标上报（60 秒间隔）、配置轮询
- **WebSocket** —— 按需建立连接，用于脚本执行期间的实时日志流和交互式终端会话

<Aside type="tip">
  如果主机位于防火墙后，请确保允许到 Server 的出站 HTTP/HTTPS 和 WebSocket 连接。Agent 始终主动发起连接 —— 不需要开放任何入站端口。
</Aside>

## 验证 Agent 状态

启动 Agent 后，在 EasyShell Web 界面中验证：

1. 导航到 **主机管理**
2. 新 Agent 应显示为绿色状态指示
3. 点击主机查看实时指标

如果 Agent 未出现，检查 Agent 日志：

```bash
journalctl -u easyshell-agent -f
```
